# Стальной Бастион — запуск в Telegram

Игра — это статический сайт (HTML, CSS и JS без сборки), который открывается внутри Telegram как Mini App. Чтобы её запустить, нужно:

1. Опубликовать папку проекта по адресу **HTTPS**.
2. Создать бота в @BotFather и привязать к нему этот адрес.

Телеграм открывает Mini App только по `https://`. Адреса `http://` и `localhost` не подойдут.

---

## 1. Проверка в браузере

Открыть `index.html` двойным кликом не получится: ES-модули не работают через `file://`. Нужен локальный сервер:

```bash
cd /путь/к/Battle
python3 -m http.server 8000
```

Откройте http://localhost:8000. В правом верхнем углу должно быть написано **«БРАУЗЕР»**, и игра должна запускаться. Рекорд в этом режиме хранится в `localStorage`.

---

## 2. Публикация по HTTPS

Подойдёт любой хостинг статики. Ниже три варианта, от самого быстрого.

### Вариант А. Netlify Drop (без регистрации репозитория, около минуты)

1. Откройте https://app.netlify.com/drop.
2. Перетащите туда папку `Battle` целиком.
3. Скопируйте выданный адрес, например `https://steel-bastion-123.netlify.app`.

### Вариант Б. GitHub Pages

```bash
cd /путь/к/Battle
git init
git add .
git commit -m "Steel Bastion"
git branch -M main
git remote add origin https://github.com/<логин>/steel-bastion.git
git push -u origin main
```

Затем в репозитории откройте **Settings → Pages**, выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/steel-bastion/`.

Все пути в проекте относительные (`./styles.css`, `./src/main.js`), поэтому работа из подпапки ничего не ломает.

### Вариант В. Туннель для разработки (без деплоя)

Это удобно, когда нужно быстро проверить правки прямо в Telegram. Локальный сервер из шага 1 должен быть запущен.

```bash
# brew install cloudflared
cloudflared tunnel --url http://localhost:8000
```

Команда выведет временный адрес вида `https://xxxx.trycloudflare.com`. Он меняется при каждом запуске, поэтому после перезапуска туннеля адрес в BotFather (шаг 3) нужно обновить.

---

## 3. Создание бота и подключение Mini App

Все действия выполняются в чате с [@BotFather](https://t.me/BotFather).

### 3.1. Создать бота

1. Отправьте `/newbot`.
2. Введите имя, например `Стальной Бастион`.
3. Введите username, который заканчивается на `bot`, например `steel_bastion_bot`.
4. BotFather пришлёт токен. Для этой игры он не нужен (сервера у неё нет), но храните его в секрете.

### 3.2. Подключить игру

Есть три способа. Достаточно одного, но их можно и сочетать.

**Кнопка меню в чате с ботом** (самый простой способ):
1. `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Отправьте HTTPS-адрес игры.
3. Отправьте подпись кнопки, например `Играть`.

После этого в чате с ботом слева от поля ввода появится кнопка, которая открывает игру.

**Главное Mini App бота** (кнопка «Открыть» в профиле бота и в поиске):
1. `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App**.
2. Отправьте HTTPS-адрес игры.

**Прямая ссылка, которой можно делиться:**
1. Отправьте `/newapp` и выберите бота.
2. Заполните название, описание и картинку 640×360. GIF можно пропустить командой `/empty`.
3. Отправьте HTTPS-адрес игры.
4. Введите короткое имя, например `play`.

Получится ссылка `https://t.me/steel_bastion_bot/play`, которая открывает игру в один клик.

## 4. Проверка в Telegram

Откройте бота и нажмите кнопку меню или перейдите по ссылке. Признаки того, что всё работает:

- в правом верхнем углу написано **«TELEGRAM MINI APP»**, а внизу — **«НА СВЯЗИ: ВАШЕ_ИМЯ»**;
- во время боя в шапке Telegram появляется кнопка **«Назад»**, которая ставит игру на паузу;
- при попытке закрыть приложение во время боя Telegram просит подтверждение;
- рекорд сохраняется в облаке Telegram (CloudStorage) и одинаков на всех устройствах. Для этого нужен клиент Telegram с поддержкой Bot API 6.9 или новее; на старых клиентах рекорд хранится локально.

На телефоне внизу появляются сенсорные кнопки. На компьютере управление такое: **WASD / стрелки** — движение, **пробел** — огонь, **Esc / P** — пауза, **Enter** — старт.

Если надпись остаётся «БРАУЗЕР», значит скрипт `telegram.org/js/telegram-web-app.js` не загрузился (игра ждёт его до 4 секунд). Проверьте сеть или VPN.

---

## 5. Обновление игры

Опубликуйте файлы заново (повторный Netlify Drop или `git push`). Telegram кэширует страницы, поэтому, если изменения не видны:

- полностью закройте Mini App и откройте снова;
- или добавьте к адресу в BotFather параметр версии, например `https://.../?v=2`, и обновите его через **Menu Button** / **Configure Mini App** / `/myapps`.

---

## 6. Отладка внутри Telegram

| Где | Как открыть DevTools |
|---|---|
| Браузер | https://web.telegram.org — обычные DevTools браузера (F12) |
| Telegram Desktop | **Настройки → Продвинутые настройки → Экспериментальные настройки → Enable webview inspecting**, затем ПКМ в Mini App → **Inspect** |
| Android | Включите **Enable WebView Debug** в отладочном меню Telegram (подробнее в документации ниже), затем подключите телефон по USB и откройте `chrome://inspect` в Chrome |
| iOS | В Telegram 10 раз нажмите на иконку **Настройки** → **Allow Web View Inspection**, затем Safari на Mac → меню **Разработка** → устройство |

Документация Telegram по Mini Apps: https://core.telegram.org/bots/webapps
